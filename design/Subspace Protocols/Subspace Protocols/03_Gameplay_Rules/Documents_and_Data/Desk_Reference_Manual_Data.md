## 1. Sector Star Systems & Warp Field Residue Waveforms (Day 3+)
Every ship departing a star system carries residual warp-field harmonics unique to that system's stellar type and local nebulae. Starting on **Day 3** ([[Daily_Rule_Escalation]]), the **Warp Field Residue Printer** ([[Inspection_Tools_and_Checks]]) outputs a physical analog waveform strip that must be matched against the **8 reference patterns** below *(note: patterns represent general reference archetypes alongside more randomized waveform noise per earlier design notes)*:

| Star System | Region / Primary Affiliation | Warp Waveform Pattern | Visual Strip Signature (Pixel-Art Readout) |
| :--- | :--- | :--- | :--- |
| **Veridia** | [[Galactic_Union]] Border Hub (`GUV-`) | **Smooth Sine Wave** | Clean, symmetrical rolling curves with uniform spacing. |
| **Korr-Vath** | [[Kordani]] Garrison Sector (`KDF-`) | **Sharp Sawtooth Wave** | Steep vertical rises with slanted downward drops; crisp and rigid. |
| **Dul-Krag** | [[Brengop]] Deep-Mine Core (`BMC-`) | **Blocky Square Wave** | Flat horizontal tops and bottoms with sharp 90-degree step transitions. |
| **Gharok** | [[Krushvak]] Warrior Frontier (`KRW-`) | **High-Amplitude Zigzag** | Tall, sharp triangular peaks (aggressive saw-free symmetrical points). |
| **Oruun-4** | Orun ([[Independent_and_Minor_Species]]) & Mining Guild ([[Commercial_Organizations]]) Belt (`ORN-`, `MNG-`) | **Repeating Double-Pulse** | Pairs of tight twin bumps separated by clean flat baseline gaps. |
| **Caldera Rim** | Free Trader / Far-Line Lane ([[Commercial_Organizations]], [[Independent_and_Minor_Species]]) (`FTV-`, `FTC-`, `TLV-`, `PRJ-`) | **Alternating Tall-Short Wave** | Repeating cycle of one tall peak followed by one noticeably shorter peak. |
| **Solvane** | Zenith Interstellar Hub ([[Commercial_Organizations]]) (`ZNI-`) | **Stepped Arch Wave** | Smooth rounded domes sitting on a flat lower baseline. |
| **The Ashen Rift** | Restricted [[The_Concord]] War-Graveyard / Ion Nebula | **Chaotic Static Spikes** | Erratic vertical seismograph spikes and broken gaps. **Red-flag origin**—never a valid civilian route without explicit [[The_Bulwark_Pact]] security clearance. |

- `[CONFLICT: See _Conflicts_and_Plot_Holes.md]` — Earlier notes (`Subpsace protocols info.pdf` Section 2) listed *Earth → Obulon Nebula* as a residue example, whereas this 8-system chart defines the Day 3+ Sector Signature Guide (`FTL_and_Stellar_Stoker`, `Brown_Dwarf_System`).

## 2. Species Biometric Reference Chart (Automatic Bio-Scanner — Day 6+)
The **Automatic Bio-Scanner** ([[Inspection_Tools_and_Checks]]) runs passively in the background for **5–10 seconds** once shields drop and the [[Data_Slate_and_Telemetry|Data Slate]] transmits, comparing live bridge life-support and cellular telemetry against the captain's declared species:
- **GREEN Flash:** Live telemetry matches the declared species profile (and cargo holds contain no undeclared life forms on Day 10+).
- **RED Flash:** Biometric mismatch (impostor, forged species ID, or Dopple instability) OR living bio-signatures detected in the cargo hold (check manifest on Day 10+).

| Species | Cabin Atmosphere / Gravity | Baseline Body Temp | Distinctive Bio-Marker (Scanner Readout) |
| :--- | :--- | :--- | :--- |

| **Thanes** ([[Galactic_Union]]) | Cold, Dry O2 (1.1G) | Cool (31°C) | High skeletal mineral density (titanium-pale physiology). |
